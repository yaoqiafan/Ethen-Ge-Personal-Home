# OpenClaw适配器手动安装指南

如果自动安装脚本有问题，请按照以下步骤手动安装：

## 步骤1：检查Node.js
打开命令提示符，运行：
```cmd
node --version
```
如果显示版本号（如 v18.x.x），则Node.js已安装。

如果没有安装，请从 https://nodejs.org/ 下载安装。

## 步骤2：安装依赖
在适配器目录中运行：
```cmd
cd C:\Users\Administrator\source\repos\Ethen-Ge-Personal-Home\openclaw-adapter
npm install
```

## 步骤3：创建环境配置文件
在Vue项目根目录创建 `.env.development` 文件，内容如下：
```
VITE_PF_API_URL=http://localhost:3001/api/v1
VITE_PF_WS_URL=ws://localhost:3002

# 站点基础信息配置
VITE_ICP_NUMBER=苏ICP备2024123968号
VITE_PUBLIC_SECURITY_NUMBER=粤公网安备 44010602XXXXXX号
VITE_OWNER_NAME=葛刘楼
```

## 步骤4：创建启动脚本
在适配器目录创建 `start.bat` 文件，内容如下：
```bat
@echo off
echo 启动OpenClaw适配器...
node server.js
pause
```

## 步骤5：启动服务

### 启动适配器
双击 `start.bat` 或运行：
```cmd
node server.js
```

应该看到输出：
```
=========================================
OpenClaw适配器服务已启动
HTTP API: http://localhost:3001
WebSocket: ws://localhost:3002
健康检查: http://localhost:3001/health
=========================================
```

### 启动Vue前端
在Vue项目目录运行：
```cmd
cd C:\Users\Administrator\source\repos\Ethen-Ge-Personal-Home
npm run dev
```

## 步骤6：测试连接

### 测试适配器
打开浏览器访问：http://localhost:3001/health

应该看到JSON响应：
```json
{
  "success": true,
  "message": "OpenClaw适配器运行正常",
  "timestamp": "...",
  "openclaw": {
    "gateway": "http://localhost:18789",
    "status": "connected"
  }
}
```

### 测试API
访问：http://localhost:3001/api/v1/system/status

应该看到系统状态数据。

## 步骤7：访问前端
打开浏览器访问：http://localhost:5173

现在PFSystemStatus、PFFileManager、PFMonitorConsole组件应该可以正常工作了。

## 常见问题

### 1. 端口被占用
如果3001或3002端口被占用，修改 `server.js` 文件：
```javascript
const PORT = 3001; // 改为其他端口，如3003
// 和
const wss = new WebSocket.Server({ port: 3002 }); // 改为其他端口，如3004
```

同时更新 `.env.development` 文件中的端口号。

### 2. npm install 失败
尝试清理缓存后重试：
```cmd
npm cache clean --force
npm install
```

### 3. 前端无法连接
检查：
1. 适配器是否运行（http://localhost:3001/health）
2. Vue前端是否运行（http://localhost:5173）
3. 浏览器开发者工具控制台是否有错误

### 4. WebSocket连接失败
检查OpenClaw网关是否运行：
```cmd
openclaw gateway status
```
