7. 问题诊断

常见问题：

  • 适配器未运行：运行 node simple-server.js
  • 端口被占用：修改server.js中的端口号
  • 环境变量未加载：检查.env.development文件
  • Vite代理配置错误：检查vite.config.ts
  • CORS问题：确保使用Vite代理或配置CORS

快速修复：

  1. 确保适配器运行：http://localhost:3001/health 返回成功
  2. 确保Vue前端运行：http://localhost:5173 可访问
  3. 检查浏览器控制台错误信息
  4. 使用此页面进行逐步测试
