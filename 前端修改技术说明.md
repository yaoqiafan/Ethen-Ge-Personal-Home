# 前端修改技术说明

## 项目概述
这是一个Vue 3 + TypeScript项目，原本设计连接PF.AutoFramework后端API。现在需要修改为直接连接OpenClaw网关服务。

## 当前架构问题
1. 前端代码依赖`pfKnowledgeService.ts`中的PF API接口
2. API地址配置为`http://localhost:8080/api/v1`和`ws://localhost:8081/api/v1/ws`
3. 这些后端服务不存在，导致前端无法连接

## 目标架构
```
Vue前端 → OpenClaw网关 (http://localhost:18789)
```

## 需要修改的文件

**当前**：无相关配置
**修改为**：

### 2. 服务层文件 (`src/services/pfKnowledgeService.ts`)

#### 2.1 修改基础URL配置
**当前**：
```typescript
const BASE_URL = (import.meta.env.VITE_PF_API_URL as string | undefined) ?? 'http://localhost:8080/api/v1'
const WS_URL   = (import.meta.env.VITE_PF_WS_URL  as string | undefined) ?? 'ws://localhost:8081/api/v1/ws'
```

**修改为**：
```typescript
// 优先使用OpenClaw配置，保持向后兼容
const BASE_URL = (import.meta.env.VITE_OPENCLAW_API_URL as string | undefined) 
  ?? (import.meta.env.VITE_PF_API_URL as string | undefined) 
  ?? 'http://localhost:18789/api'
  
const WS_URL = (import.meta.env.VITE_OPENCLAW_WS_URL as string | undefined)
  ?? (import.meta.env.VITE_PF_WS_URL as string | undefined)
  ?? 'ws://localhost:18789/ws'
```

#### 2.2 修改API端点映射
OpenClaw网关的API结构与PF不同，需要重新映射：

**系统状态相关**：
- `GET /api/v1/system/status` → `GET /api/system/status` 或直接使用OpenClaw状态API
- `POST /api/v1/system/refresh` → 可移除或调用OpenClaw相应功能
- `GET /api/v1/health` → `GET /health` (OpenClaw健康检查)
- `GET /api/v1/diagnostics` → 可移除或使用OpenClaw诊断功能

**建议修改方案**：
创建新的服务文件 `src/services/openclawService.ts`，专门处理OpenClaw API调用。

### 4. 创建新的OpenClaw服务文件

```typescript

const OPENCLAW_API = import.meta.env.VITE_OPENCLAW_API_URL || 'http://localhost:18789'
const OPENCLAW_WS = import.meta.env.VITE_OPENCLAW_WS_URL || 'ws://localhost:18789/ws'
const OPENCLAW_TOKEN = 'd35fefbd61c79bac0feedcc07ce68132f38b2c287a2fb439' // 从openclaw.json获取

// 系统状态接口（适配原有PF接口）

// OpenClaw WebSocket连接
export function useOpenClawMonitor() {
  const isConnected = ref(false)
  const logs = ref<any[]>([])
  let ws: WebSocket | null = null
  
  function connect() {
    ws = new WebSocket(OPENCLAW_WS)
    
    ws.onopen = () => {
      isConnected.value = true
      console.log('已连接到OpenClaw WebSocket')
      
      // 发送认证（如果需要）
      if (OPENCLAW_TOKEN) {
        ws!.send(JSON.stringify({ type: 'auth', token: OPENCLAW_TOKEN }))
      }
    }
    
    ws.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data)
        logs.value.unshift({
          id: `log_${Date.now()}`,
          timestamp: new Date().toISOString(),
          level: 'info',
          source: 'openclaw',
          message: data.message || JSON.stringify(data)
        })
        
        // 保持日志数量合理
        if (logs.value.length > 200) {
          logs.value.splice(200)
        }
      } catch (error) {
        console.error('WebSocket消息解析错误:', error)
      }
    }
    
    ws.onerror = (error) => {
      console.error('WebSocket错误:', error)
    }
    
    ws.onclose = () => {
      isConnected.value = false
      console.log('WebSocket连接已关闭')
    }
  }
  
  function disconnect() {
    if (ws) {
      ws.close()
      ws = null
    }
  }
  
  function send(message: any) {
    if (ws && ws.readyState === WebSocket.OPEN) {
      ws.send(JSON.stringify(message))
    }
  }
  
  function clearLogs() {
    logs.value = []
  }
  
  onUnmounted(() => {
    disconnect()
  })
  
  return {
    isConnected,
    logs,
    connect,
    disconnect,
    send,
    clearLogs
  }
}
```

### 7. 模拟数据方案（快速实现）

如果OpenClaw没有完全对应的API，可以使用模拟数据让前端先运行起来：

在 `openclawService.ts` 中提供模拟数据，同时标记哪些是模拟的：

```typescript
// 模拟数据标志
const USE_MOCK_DATA = true

export const openclawService = {
  async getSystemStatus(): Promise<SystemStatus> {
    if (USE_MOCK_DATA) {
      // 返回模拟数据
      return mockSystemStatus()
    } else {
      // 调用真实API
      return fetchRealStatus()
    }
  }
}
```
